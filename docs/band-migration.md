# 밴드 기능 이관표 (RPBA → AFTERLOG)

명세 v1.1 4.2절 기준. 상태: 구현 완료 / 후속 예정 / 원본 버그로 재설계 / 미확인

| 기존 기능 (legacy `band.js`) | AFTERLOG 처리 | 상태 |
|---|---|---|
| 세 가지 형식 자동 감지·수동 선택 | 저장 페이지·HTML 조각·텍스트 복사를 판별, 가장 정확한 입력 사용. 여러 게시글이면 사용자가 선택 | 글과 댓글: 완료 / 게시글 모음: 후속(샘플 필요) / 댓글 모음: 저장 페이지 뒤쪽 목록만 완료 |
| 텍스트 파서 (`parseBandPost` 등) | 숫자 줄·`* ` 줄·UI 단어를 무조건 지우던 규칙 폐기. 모든 줄 분류, 미분류 보존 | 원본 버그로 재설계 |
| 입력 시 인물 설정 초기화 | 원문과 편집 문서 분리. 재가져오기는 새 문서 | 원본 버그로 재설계 |
| 멘션 = 답글 판정 | HTML 구조로 부모 판정, 멘션은 표시만. 텍스트에서는 '부모 미확정 + 제안' | 원본 버그로 재설계 |
| 댓글 모음 첫 줄만 표시·편집 | 전문 저장·표시·내보내기 | 원본 버그로 재설계 |
| 인물 표시 이름·설명·프로필 사진·이름 색 | 원래 이름·설명 보존, 되돌리기, 인물 분리·합치기 | 완료 |
| 인물 숨기기·색 초기화 | 보기 필터(자료 삭제 아님), 숨긴 본문은 내보낸 파일 소스에도 없음 | 완료 |
| 라이트·다크 | 편집기 테마와 출력 테마 분리 | 완료 |
| 폰트·크기(전체/이름/프로필/본문/댓글) | 연동/개별, 초기화 | 완료 |
| 날짜·읽음·리액션·원글 발췌 표시 | 데이터와 표시 분리. 반응은 확인된 값만 표시 | 완료 |
| 미리보기 직접 수정 | 상태 모델에 순수 텍스트로 반영, 한글 조합 보호, 원본 복원 | 완료 |
| 드래그·위아래 이동 | 안내선, Alt+↑/↓, 메뉴. 답글은 따라 이동 | 완료 |
| 댓글/답글 전환 | 검사 패널에서 실제 부모 선택, 빠른 메뉴 | 완료 |
| 우클릭 편집·이동·삭제 | ⋯ 메뉴·우클릭·키보드 공통. 나누기·합치기·복제·삭제(답글 포함/올리기) | 완료 |
| 이미지 자리 업로드·교체 | 자산 ID로 연결, 미확보 목록, 미사용 자산 정리 | 완료 (게시글 모음은 후속) |
| 좌우 패널 크기 조절 | 최소/최대 폭, 접기, 폭 기억, 키보드 조절 | 완료 |
| HTML·PNG 저장 | 데이터 기반 출력, 단일 HTML(오프라인), 분할 PNG(ZIP) | 완료 |
| JPG·HTML 복사·자산 폴더형 HTML | | 후속(A3) |
| 전체 초기화 | 표시 설정 초기화 / 프로젝트 휴지통 / 영구 삭제 분리 | 완료 ('앱 전체 데이터 삭제'는 후속) |
| 실행취소·다시실행 | 본문·인물·설정·이동·부모·삭제 등 문서 전체, 100단계, 연속 타이핑 묶음 | 완료 |
| 저장 (없었음) | IndexedDB 자동 저장, 저장 실패 표시, 다른 탭 충돌 방지, .afterlog 복구 파일 | 신규 |

카톡·네이버카페·트위터 이관표는 해당 단계 시작 전에 따로 작성한다.
