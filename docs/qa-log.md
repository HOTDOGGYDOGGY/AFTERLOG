- 검사: 로컬 실행판 e2e(첫 화면 '파일 열기'로 수집 확장 파일 열기, 합성 샘플 tests/fixtures/afterlog), 확장 e2e 9개(검색 주소 둘 → 검색어 자동 인식 → 4개 수집 → HTML ZIP 5개 파일), 단위 148, 웹 e2e 14.
