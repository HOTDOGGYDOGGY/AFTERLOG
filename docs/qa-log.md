# 검수 기록

## 2026-09-25 · 밴드 우선 사용판(A2) + v1.1 반영

환경: Linux 컨테이너, Node 22.22, Chromium(Playwright 1.56.1 번들, 헤드리스). Windows Chrome/Edge 실기 검수는 아직 안 함.

### 자동 테스트
- `npm test` (Vitest): 66개 통과. 실제 샘플 테스트 포함(`tests/private/`에 샘플이 있을 때만 실행, 저장소에는 올리지 않음).
- `npm run e2e` (Playwright): 6개 통과.
  - 합성 샘플: 가져오기 → 본문·인물·테마 수정 → 자동 저장 → 새로고침 복원 → .afterlog 저장 → 새 브라우저 환경에서 복구 → 오프라인 HTML(390px, 외부 요청 0, 가로 스크롤 없음) → 분할 PNG(ZIP, 여러 장)
  - 다른 탭에서 같은 문서를 열면 이전 탭 읽기 전용, 편집권 인계
  - 텍스트 복사 붙여넣기 → 줄 분류 → 제안 모두 적용 → 실행취소
  - 인물별 보기 → 항목으로 이동
  - 실제 샘플 ZIP: 댓글 17/답글 9, 프로필 이미지 18곳 모두 로드, 1280·1440 화면, 다크 출력, 오프라인 HTML 390px, 분할 PNG

### 눈으로 확인한 화면
- 편집기 1280×720, 1440×900: 잘림·겹침·가로 스크롤 없음
- 실제 샘플 다크 HTML 390px: 전체 17개 댓글, 답글 들여쓰기, 프로필 사진, 가로 스크롤 없음
- 실제 샘플 분할 PNG(2배, 최대 1500px): 2장. 1장 끝 = 12:17 댓글, 2장 시작 = 7:45 답글. 빠지거나 겹친 항목 없음

### 알려진 제한
- 이 컨테이너의 헤드리스 Chromium은 한글 다운로드 파일명을 `download`로 바꾼다. 일반 Chrome에서는 한글 이름이 그대로 쓰인다(테스트는 a[download] 값을 확인).
- 긴 항목 하나가 한 장보다 길면 줄 경계에서 자르며, 줄 경계가 없으면 강제로 자르고 알려 준다.
