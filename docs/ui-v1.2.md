# 통합 UI·밴드 원형 보기 개편 (명세 v1.2) — 기능 위치 대조표

적용 버전: 웹 앱 0.3.0 / 수집 확장 0.1.1 (2026-09-25).
기준: `AFTERLOG_통합UI_UX_디자인개편명세_v1.2.md` 27절(다크 기본 + 플랫폼 원형 UI/UX) 우선.

## 화면 구조

- **공통 셸**: 상단바 48px(AFTERLOG · 프로젝트 이름 ▾ · 저장 상태 · [모듈 버튼] · 프로젝트 저장 · 내보내기 · 설정) + 플랫폼 줄 40px(밴드 / 카카오톡 / 트위터 / DM / 카페 / 짓시, 오른쪽에 모듈의 가져오기).
  모듈 버튼(실행취소·원문 보기·꾸미기·내용 편집·내보내기)은 활성 모듈만 슬롯에 넣는다. 숨은 모듈의 버튼·단축키는 동작하지 않는다.
- **밴드(새 편집기)**: 기본은 원형 보기. 홈 피드(왼쪽 밴드 정보 · 가운데 글 피드 · 오른쪽 채팅 목록) → 글 상세 레이어(600px, 딤 배경, 오른쪽 위 닫기) → 인물 프로필 → 해당 댓글.
  꾸미기(오른쪽 패널)와 내용 편집(작업 화면)은 사용자가 열 때만 보인다.
- **카카오톡·트위터·DM·카페(기존 편집기)**: RPBA 원래 화면을 같은 출처 iframe으로. 원래 입력·설정 패널을 그대로 쓰고, 셸의 왼쪽·오른쪽 패널은 없다.
- **짓시(원문 보관)**: 텍스트·파일을 원문 그대로 보관하고 평문으로 보여 준다. 채팅 모양으로 추측 변환하지 않는다.

## 새로 생긴 것 / 아직 아닌 것

- 신규: 밴드 원형 보기(피드·상세·프로필·해시 주소·뒤로가기·스크롤 복원), 꾸미기 모델(`view.style` v1), 프리셋 저장·설정 복사/붙여넣기·모든 글에 적용·새 글 기본값, 원형 비교, 기존 도구 연결, 짓시 원문 보관.
- 후속(구현 안 함): 사용자 폰트 파일, 책갈피·내부 메모, 인장 일괄 매칭, 디자인 전후 비교 화면, 답글 접기, 카톡·트위터 원형 재설계(U4), 짓시 전용 편집기(원본 소스 없음).
- 수집 확장으로만 채울 수 있는 것(실제 샘플 필요): 프로필 상세·스토리, 표정 종류·반응자, 인물별 댓글 원래 목록, 밴드 채팅.

## 기존 도구(RPBA) 연결에서 고친 것

원본은 `public/legacy/`에 먼저 그대로 복사하고(커밋 `a8e444f`), 연결에 필요한 부분만 바꿨다. 바꾼 줄에는 `AFTERLOG:` 주석이 있다.

| 문제(원본) | 처리 |
|---|---|
| 카톡: `#btnSaveJpg`가 없어 초기화가 중간에 멈춤(설정 복원·첫 렌더링 안 됨) | 원래 스크립트가 찾는 요소를 숨겨 둠 |
| 카페: `#undoBtn` 등이 없어 입력해도 미리보기·인물 목록이 안 나옴 | 같은 방식. 상단 실행취소를 카페 실행취소로 전달 |
| 트위터: `#helpBtn`이 없어 내보내기·초기화 등록이 멈춤 | 같은 방식 |
| 플랫폼 전환이 두 벌(app.js·patch.js)이라 버튼 상태가 어긋남 | patch.js를 쓰지 않음. 전환은 통합 셸 하나 |
| `getActiveTextArea`가 트위터·밴드에서도 카페 입력칸을 잡음 | 모듈별 iframe이 자기 입력칸만 다룸 |
| 저장 버튼이 다른 도구를 캡처할 수 있음 | 내보내기는 활성 모듈에만 요청 |
| 숨은 도구의 단축키가 함께 동작 | 단축키는 각 iframe 안에서만, 밴드 단축키는 밴드가 보일 때만 |
| html2canvas를 CDN에서 불러와 오프라인이면 조용히 실패 | 로컬 번들(`legacy/vendor/html2canvas.min.js`) |
| 트위터 `postMessage('*')` | 제거. 다리는 출처·보낸 창·protocol·moduleId 확인 |
| 카톡: 원문 해시별 localStorage라 글을 고치면 인물 설정이 초기화되고 저장 공간을 계속 씀 | 프로젝트에 저장, 원문을 고쳐도 인물 설정을 이어받음 |
| 트위터: 글을 고치거나 형식을 바꾸면 올린 사진이 사라짐 | 사진·인증 표시를 이어받음 |
| 예시 대화·글을 입력칸에 자동으로 채움 | 채우지 않음(입력칸 안내문만) |
| 960px 미만 차단 화면 | 쓰지 않음 |
