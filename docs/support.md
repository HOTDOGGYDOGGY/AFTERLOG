# 지원 범위 (2026-09-25 기준)

"실제 검증"은 사용자가 준 실제 샘플(밴드저장예시.zip)로 확인했다는 뜻이다. "합성 검증"은 익명 합성 자료로만 확인했다.

| 입력 | 상태 | 검증 |
|---|---|---|
| 밴드 게시글+댓글, 저장 페이지 HTML (+ `_files` 이미지 / 폴더째 ZIP) | 지원 | 실제 검증 (게시글 1, 댓글 17 = 최상위 8 + 답글 9, 프로필 9개) |
| 밴드 게시글+댓글, 게시글 영역 HTML 조각 (TXT·붙여넣기) | 지원. 이미지는 원격 링크만 기록하고 자동으로 받지 않음 | 실제 검증 |
| 밴드 게시글+댓글, 화면 텍스트 복사 (TXT·붙여넣기) | 대체 경로. 답글 관계·정확한 시각·사진·표정 없음. 부모 미확정 + 제안 | 실제 검증 (본문 17개가 HTML과 일치) |
| 멤버 댓글 모음 (저장 페이지 뒤쪽 목록) | 가져오기 가능. 전체 목록인지 확인 필요로 표시 | 실제 페이지에 있던 60개로 확인. 완전한 목록 샘플은 아님 |
| 게시글 이미지·댓글 첨부 이미지 | 구조상 지원 | 합성 검증만 (실제 샘플에 없음) |
| 표정·하트 수, 반응 종류, 반응자 | 데이터 구조 있음. 값이 보이는 경우만 '값 있음' | 실제 샘플에 양수 반응 없음 → 미검증 |
| 게시글 모음 | 미지원 | 샘플 필요 |
| 프로필 상세·스토리·프로필 댓글/반응 | 미지원 | 샘플 필요 |
| 인물별 글/댓글 목록 | 현재 확보한 문서로 재구성한 목록만 (원래 목록 저장본 아님) | 실제 샘플로 화면 확인 |
| 밴드 채팅 | 미지원 | 샘플 필요 |
| 카카오톡·네이버카페·트위터/X·기타 DM | 미지원 (B 단계) | |

## 필요한 샘플

- 게시글 모음 화면 저장 페이지 1개
- 표정·하트가 실제로 달린 게시글/댓글 저장 페이지 (가능하면 반응자 목록을 연 상태도)
- 멤버 프로필 상세(스토리·프로필 댓글 포함) 저장 페이지
- 밴드 채팅: 내보내기 파일 또는 채팅방을 연 상태의 저장 페이지
